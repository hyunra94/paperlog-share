# 같이 쓰는 Paper Log (공유 앱)

PaperLog 중 **숨기지 않은 일정**과 **공개한 카테고리의 지출**만 다른 사람과 함께 보고 쓰는 앱이에요.
데이터는 PaperLog와 같은 Notion DB에 저장돼요. 그래서 공유 앱에서 입력한 내용은 PaperLog에도 그대로 보여요.

PaperLog 저장소와는 완전히 따로 있어요. PaperLog 코드나 Worker는 건드리지 않아요.

- 화면: 이 저장소 루트 (`index.html`) → GitHub Pages로 배포하면 `https://hyunra94.github.io/paperlog-share/`
- Worker: `worker/` → `https://paperlog-share.hyunra94.workers.dev`
- PaperLog Worker의 `SECRET_KEY`는 쓰지 않아요. 공유 Worker는 공개 범위 밖의 데이터를 읽지도, 쓰지도 않아요.

## 무엇이 공유되나
- **일정**: 모든 일정이 공유돼요. 다만 Notion 일정 DB의 **`공유 안 함`** 체크박스에 체크한 일정과 취소한 일정은 빠져요. 체크는 관리자(나)만 할 수 있어요. Notion에서 해도 되고, 공유 앱에서 일정을 열어 해도 돼요. 숨긴 일정은 관리자 화면에만 🙈 표시와 함께 흐리게 보여요.
- **가계부**: Subject(카테고리)가 **`공유`**인 지출만 보여요. 누가 얼마 냈는지와, 똑같이 나눌 때 누가 누구에게 얼마를 보내면 되는지(참고용)도 보여 줘요.
- **하자·AS**: 일정을 만들 때 `📅 일정` / `🔧 하자·AS` 중에서 골라요. 하자·AS는 따로 모아 보는 탭이 있어요. 증상, 접수번호, 기사님 연락처, 처리 결과는 상황 메모에 적어요.
- 다른 카테고리도 같이 보이게 하려면 관리자 설정(⚙)에서 더 체크하면 돼요.

PaperLog에서 쓰는 법: 언니에게 보이면 안 되는 일정은 Notion에서 `공유 안 함`에 체크해요. 같이 쓴 돈은 카테고리를 `공유`로 고르면 돼요.

> ⚠️ **Notion 준비하기**를 눌러 `공유 안 함` 속성을 만든 다음, 숨길 일정을 먼저 체크하고 나서 언니를 멤버로 추가하세요. 체크하지 않은 일정은 지난 일정까지 모두 보여요.

## 아이폰에서 쓰기
1. **Safari**로 앱 주소를 열어요. 아이폰의 Chrome에서는 홈 화면 추가가 잘 안 될 수 있어요.
2. 아래쪽 **공유 버튼(□↑) → 홈 화면에 추가**를 눌러요.
3. **홈 화면에 생긴 아이콘으로 앱을 연 다음** 이름과 코드로 로그인해요.
   - 아이폰은 Safari와 홈 화면 앱이 로그인 정보를 따로 저장해요. 그래서 Safari에서 로그인했어도 홈 화면 앱에서는 한 번 더 로그인해야 해요.
   - Safari에서만 쓰면 한동안 열지 않았을 때 로그인이 풀릴 수 있어요. 홈 화면 앱으로 쓰면 30일 동안 로그인이 유지돼요.
4. 홈 화면 앱에는 새로고침 버튼이 없어요. 그래서 앱을 다시 열면 내용을 알아서 새로 불러와요.

## 권한
| 누구 | 할 수 있는 것 |
|---|---|
| 관리자 (ADMIN_KEY로 로그인) | 공유된 모든 항목 보기·수정·삭제, 공유 설정 |
| 멤버 (이름 + 개인 코드) | 공유된 항목 보기, 누구 몫으로든 추가(대신 추가), **담당자 본인이거나 직접 입력한 항목만** 수정·삭제 |

- PaperLog에서 입력한 기존 항목은 담당자가 비어 있으므로 관리자 것으로 봐요.
- 지출의 결제수단(Card), 일정의 개인 메모와 프로젝트는 공유 앱에 보이지 않아요.
- 멤버는 `공유 안 함`을 바꿀 수 없어요. 숨긴 일정은 멤버가 열거나 고칠 수도 없어요.

## 처음 배포하기
`worker` 폴더에서 실행해요.

```bash
npx wrangler kv namespace create SHARE_KV
```
→ 출력된 id를 `worker/wrangler.toml`의 `REPLACE_WITH_SHARE_KV_ID` 자리에 넣어요.

```bash
npx wrangler secret put NOTION_TOKEN
```
→ PaperLog Worker에 넣은 것과 같은 Notion 토큰을 넣어요.

```bash
npx wrangler secret put ADMIN_KEY
```
→ 공유 앱 관리자 코드예요. **PaperLog SECRET_KEY와 다른 값**으로, 길게 정해 주세요.

```bash
npx wrangler deploy
```

화면은 GitHub 저장소 Settings → Pages에서 `main` 브랜치의 루트(`/`)를 배포 대상으로 고르면 열려요.
다른 주소(예: 직접 연결한 도메인)를 쓰면 `worker/wrangler.toml`의 `CORS_ORIGIN`에 그 주소를 추가해요.

## 처음 설정하기
1. 공유 앱 주소에서 이름은 비워 두고 ADMIN_KEY로 로그인해요.
2. 왼쪽 위 ⚙ → **Notion 준비하기** 버튼을 눌러요. 없는 것만 만들어요.
   - 일정 DB: `공유 안 함`(체크박스), `공유 담당자`(선택), `공유 작성자`(텍스트), `공유 메모`(텍스트), `공유 분류`(선택: 일정 / 하자·AS)
   - 지출 DB: `공유 담당자`(선택), `공유 작성자`(텍스트)
3. Notion에서 숨길 일정의 `공유 안 함`에 체크해요. Notion 표에서 필터를 걸고 여러 개를 한꺼번에 체크하면 편해요.
4. 내 이름과 함께 쓸 사람(예: 언니 + 코드)을 정하고 저장해요. 가계부는 기본으로 `공유` 카테고리만 보여요.
5. 함께 쓸 사람에게 주소와 각자의 이름, 코드를 알려 주세요.

멤버를 목록에서 빼면 그 사람은 바로 로그아웃돼요.
